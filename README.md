# Adaptive Neural

Экспериментальная C#-лаборатория **самоорганизующейся разреженной нейронной сети**. Исследуем гипотезу, при которой локальная активность, гомеостатическая регуляция и структурная пластичность могут приводить к новым устойчивым функциональным ансамблям.

> Это **не** искусственный общий интеллект и не доказательство возникновения разума. Стабилизация активности сама по себе не гарантирует осмысленного обучения, абстракции или сознания. Проект нужен, чтобы проверять отдельные механизмы измеримыми экспериментами.

## Запуск

Требуется [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0). Внешних NuGet-пакетов нет.

```bash
dotnet run --project src/AdaptiveNeural.Server
```

Открыть адрес, напечатанный ASP.NET Core в консоли (`http://localhost:5xxx`; при необходимости задать фиксированный порт):

```bash
dotnet run --project src/AdaptiveNeural.Server --urls http://localhost:5050
```

Теперь интерфейс доступен на **http://localhost:5050**. Нажми на граф сети, чтобы добавить локальный импульс; кликай по 2D-миру, чтобы добавлять пищу или опасности. Можно ставить симуляцию на паузу, выполнять шаги, менять скорость и параметры локальной адаптации.

## Что реализовано

- **Разреженный ориентированный граф**: только списки исходящих связей; на шаге используется `O(N + E + N·P)`, где N — нейроны, E — связи, P — число активных внешних импульсов (не больше 12). Матрицы `N × N` нет.
- **Локальное возбуждение** нейронов с ограниченной активацией `[0, 1]`.
- **Hebbian-пластичность** с небольшим затуханием весов и отрицательными связями.
- **Гомеостаз**: локальная подстройка порога под скользящую среднюю активности; ограничение диапазонов.
- **Реконфигурация**: новые связи и нейроны появляются преимущественно у активных внутренних групп; длительно слабые связи удаляются.
- **Ресурсные лимиты**: максимум нейронов, связей и исходящих связей на нейрон; ограниченный размер пачки структурных изменений.
- **Замкнутая 2D-среда**: пища, опасности, 8 входных сенсорных каналов и 3 выходных моторных канала; движется маленький агент. Он **не получает скрытого обучающего подкрепления**: успешное пищевое поведение не обещается.
- **Локальный визуализатор**: граф сети, движение агента, телеметрия, графики активности / напряжения, стимуляция мышью и настройка параметров.
- **Детерминированный seed** для повторяемых прогонов.

Ранние группы 1–4 задаются геометрически только как начальный каркас для локального нейрогенеза; это ещё **не** механизм эмерджентного открытия или разделения групп. Сенсоры и моторы — фиксированные физические интерфейсы, а не запрограммированные представления понятий.

## Концепция первого эксперимента

1. Запустить с seed `1337`, записать среднюю активность, локальное напряжение, число связей / нейронов и траекторию агента.
2. Ввести серию импульсов в конкретной области и наблюдать, возникают ли локальные структурные изменения.
3. Сравнить повторный ответ той же области до / после опыта.
4. Повторить с выключенной структурной пластичностью (контрольная группа), затем с другой целевой активностью.
5. Проверять не просто рост сети, а **воспроизводимость, устойчивость и сохранение полезных паттернов**. Случайный дрейф агента не считать обучением.

Параметры в веб-интерфейсе меняются на лету. Начальный размер и верхние лимиты пока меняются через `POST /api/control` + `action: "reset"`. Сброс ставит модель на паузу.

## API

- `GET /api/snapshot?version=-1` — состояния, метрики, мир и полная топология.
- `GET /api/snapshot?version=<topologyVersion>` — облегчённый снимок: только активности, метрики, мир; полный граф лишь при изменении версии.
- `POST /api/stimulus` — `{"x":0.0,"y":0.0,"strength":3.0}`.
- `POST /api/world/spawn` — `{"x":0.2,"y":-0.1,"hazard":false}`.
- `POST /api/control` — `{"action":"pause"}`, `{"action":"play","speed":4}`, `{"action":"step"}`, `{"action":"reset","initialNeurons":256}`, `{"targetActivity":0.2,"growthThreshold":0.06,"learningRate":0.003,"structuralPlasticity":true}`.

## Границы прототипа / следующие исследования

- Сейчас структурный рост следует простому порогу локального напряжения. Требуются альтернативы: регуляция по качеству предсказаний, конкуренция за ресурсы, сохранение функциональности после нейрогенеза.
- Нет консолидации памяти, формирования новых сенсорных категорий, создания новых групп, обучения целенаправленному поведению и нейромодуляции.
- Для научного сравнения нужны пакетные headless-прогоны по нескольким seed, сохранение траекторий/структуры, разделение training/test и автоматические метрики памяти и обобщения.
- Визуализация ограничивает отрисовку 5500 рёбрами на кадр, **но** вычислительная сеть обрабатывает все свои связи.
- Нельзя открывать сервер в публичный интернет без аутентификации: управляющий API предназначен для локальной машины.
