# Adaptive Neural

Экспериментальная C#-лаборатория **самоорганизующейся разреженной нейронной сети**. Исследуем гипотезу, при которой локальная активность, гомеостатическая регуляция и структурная пластичность могут приводить к новым устойчивым функциональным ансамблям.

> Это **не** искусственный общий интеллект и не доказательство возникновения разума. Стабилизация активности сама по себе не гарантирует осмысленного обучения, абстракции или сознания. Проект нужен, чтобы проверять отдельные механизмы измеримыми экспериментами.

## Запуск

Требуется [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0). Внешних NuGet-пакетов нет.

```bash
dotnet run --project src/AdaptiveNeural.Server
```

Открыть адрес, напечатанный ASP.NET Core в консоли (`http://localhost:5xxx`; при необходимости задать фиксированный порт):

```bash
dotnet run --project src/AdaptiveNeural.Server --urls http://localhost:5050
```

Теперь интерфейс доступен на **http://localhost:5050**. Нажми на граф сети, чтобы добавить локальный импульс; кликай по 2D-миру, чтобы добавлять пищу или опасности. Можно ставить симуляцию на паузу, выполнять шаги, менять скорость и параметры локальной адаптации.

## Что реализовано

- **Разреженный ориентированный граф**: только списки исходящих связей; на шаге используется `O(N + E + N·P)`, где N — нейроны, E — связи, P — число активных внешних импульсов (не больше 12). Матрицы `N × N` нет.
- **Локальное возбуждение** нейронов с ограниченной активацией `[0, 1]`.
- **Hebbian-пластичность** с небольшим затуханием весов и отрицательными связями.
- **Гомеостаз**: локальная подстройка порога под скользящую среднюю активности; ограничение диапазонов.
- **Реконфигурация**: новые связи и нейроны появляются преимущественно у активных внутренних групп; длительно слабые связи удаляются.
- **Эволюция входов и выходов**: при сохраняющемся возбуждении сеть создаёт собственные виртуальные рецепторные каналы с комбинацией физических сенсоров и дополнительные моторные проекции. Неиспользуемые вторичные интерфейсы могут выводиться из роли входа/выхода; нейроны сохраняются и переводятся во внутренние.
- **Новые структурные ансамбли**: перегруженная группа может отделить совместно активные соседние нейроны в собственную группу, породить два дополнительных нейрона и сформировать локальные связи. У групп есть история происхождения — отображается в визуализаторе.
- **Ресурсные лимиты**: максимум нейронов, связей и исходящих связей на нейрон; ограниченный размер пачки структурных изменений.
- **Замкнутая 2D-среда**: пища, опасности, 12 входных сенсорных каналов и 3 выходных моторных канала; движется маленький агент. Он **не получает скрытого обучающего подкрепления**: успешное пищевое поведение не обещается.
- **Локальный визуализатор**: граф сети, движение агента, телеметрия, графики активности / напряжения, стимуляция мышью и настройка параметров.
- **Детерминированный seed** для повторяемых прогонов.

Исходные группы 1–4 геометрически задают начальную организацию. После этого сеть может сама разделять группы под давлением активности. Группировка — лишь экспериментальное приближение к развитию структур, **не доказательство возникновения смысловых абстракций**.

**Физические интерфейсы среды фиксированы: 12 сенсоров и 3 действия**. Изменяется число виртуальных рецепторов и моторных проекций в самой сети. «Новый вход» здесь означает новый способ обработки доступного сигнала, но не создание неизвестной миру модальности; «новый выход» означает дополнительный моторный узел, действующий через одно из существующих действий.

Стабильный ID нейрона не удаляется при отключении виртуального интерфейса, чтобы не ломать ссылки синапсов. Переназначенный нейрон остаётся во внутренней сети.

## Концепция первого эксперимента

1. Запустить с seed `1337`, записать среднюю активность, локальное напряжение, число связей / нейронов и траекторию агента.
2. Ввести серию импульсов в конкретной области и наблюдать, возникают ли локальные структурные изменения.
3. Сравнить повторный ответ той же области до / после опыта.
4. Повторить с выключенной структурной пластичностью (контрольная группа), затем с другой целевой активностью.
5. Проверять не просто рост сети, а **воспроизводимость, устойчивость и сохранение полезных паттернов**. Случайный дрейф агента не считать обучением.

Параметры в веб-интерфейсе меняются на лету. Начальный размер и верхние лимиты пока меняются через `POST /api/control` + `action: "reset"`. Сброс ставит модель на паузу.

## API

- `GET /api/snapshot?version=-1` — состояния, метрики, мир и полная топология.
- `GET /api/snapshot?version=<topologyVersion>` — облегчённый снимок: только активности, метрики, мир; полный граф лишь при изменении версии.
- `POST /api/stimulus` — `{"x":0.0,"y":0.0,"strength":3.0}`.
- `POST /api/world/spawn` — `{"x":0.2,"y":-0.1,"hazard":false}`.
- `POST /api/control` — `{"action":"pause"}`, `{"action":"play","speed":4}`, `{"action":"step"}`, `{"action":"reset","initialNeurons":256}`, `{"targetActivity":0.2,"growthThreshold":0.06,"learningRate":0.003,"structuralPlasticity":true}`.
- Управление эволюцией без сброса: `{"adaptiveInterfaces":true,"adaptiveStructures":true,"interfaceGrowthThreshold":0.075,"structureGrowthThreshold":0.085}`.
- Ресурсные лимиты через API: `{"maximumInputPorts":20,"maximumOutputPorts":10,"maximumStructures":12}`. Число виртуальных каналов/групп не может превышать лимиты; уже созданные каналы не удаляются автоматически при снижении лимита.
- `network.metrics` содержит число входов/выходов, созданных и отозванных портов, число структур и число новых структур.
- При обновлении `network.topologyVersion` ответ содержит `inputs`, `outputs`, `structures`; если версия та же — эти массивы опускаются как и `nodes/edges`.

## 0.3 — локальная консолидация и наблюдаемая специализация

- **Синаптическая устойчивость:** для каждого ребра хранится компактный след с числом отделённых периодами затишья эпизодов совместного возбуждения. Первый эпизод только отмечает кандидата, последующие постепенно стабилизируют связь; непрерывная высокая активность не считается повторением.
- **Стабильные связи** реже меняют вес и защищены от прунинга до угасания следа. Стабильность убывает при неактивности. Механизм локальный, без награды и внешнего учителя.
- **Профили ансамблей:** каждому внутреннему ансамблю сопоставляется статистика его средней синаптической стабильности и корреляции активности с физическими сенсорами. «Предпочтительный сенсор» — только наблюдаемая корреляция, не присвоенная метка понятия.
- **Контрольный опыт:** две идентично инициализированные сети получают равное число импульсов и общую мощность сигналов. Одна всегда видит одну пару сенсоров, другая — перемешанные пары. Структурная пластичность отключена только в этом эксперименте, чтобы сравнивать чисто синаптические изменения. В UI есть кнопка запуска, график количества стабильных связей и отклик на знакомый стимул.
- **Бюджеты:** память хранится вместе с существующими разреженными рёбрами, без матрицы `N × N`; запись агрегированной статистики по группам пропорциональна числу нейронов, сенсоров и рёбер.

Консолидация не гарантирует улучшение поведения. Случайно стабилизировавшиеся ребра могут даже мешать развитию: отчёт намеренно показывает исходные величины без утверждений, что «обучение успешно».

API: `POST /api/memory/experiment` с `{"seed":1337,"episodes":24}` (разрешено 4–48 эпизодов; параллельные запуски ограничены одним). `POST /api/control` поддерживает `memoryConsolidation`, `memoryActivationThreshold`, `consolidationRate`. `GET /api/snapshot` содержит `metrics.stableConnections`, `metrics.memoryReactivations`, `metrics.meanConsolidation`, `memoryGroups`.

## Границы прототипа / следующие исследования

- Сейчас структурный рост следует простому порогу локального напряжения. Требуются альтернативы: регуляция по качеству предсказаний, конкуренция за ресурсы, сохранение функциональности после нейрогенеза.
- Нет семантической памяти, открытия совершенно новых физических сенсорных модальностей, обучения целенаправленному поведению и нейромодуляции. Формирование нового ансамбля сейчас основано на близости и схожести активности, а не на доказанной самостоятельной семантике.
- Для научного сравнения нужны пакетные headless-прогоны по нескольким seed, сохранение траекторий/структуры, разделение training/test и автоматические метрики памяти и обобщения.
- Визуализация ограничивает отрисовку 5500 рёбрами на кадр, **но** вычислительная сеть обрабатывает все свои связи.
- Нельзя открывать сервер в публичный интернет без аутентификации: управляющий API предназначен для локальной машины.

## Эксперимент с эволюцией

1. Запусти симуляцию с включёнными «Эволюция входов и выходов» и «Образование новых ансамблей»; наблюдай исходные 12/3 интерфейса и четыре внутренние группы.
2. Несколько раз стимулируй активную область графа. При необходимости понизь пороги интерфейсов и ансамблей до `0.015`–`0.04`.
3. Следи за появлением новых виртуальных рецепторов, моторных проекций и фиолетовых областей новых структур. Сравни результат с идентичным seed и выключенной эволюцией.
4. Следи не только за числом нейронов, но и за средней активностью, стабильностью ответа на повторные стимулы и поведением в среде. Большая сеть сама по себе не означает более умную.

На обработку каждого тика по-прежнему используется разреженный граф `O(N + E)` плюс ограниченные внешние импульсы. Пересчёт структур запускается раз в 90/270/540 тиков, а проверка деактивации интерфейсов — раз в 900.

## 0.4 — экологическая среда и проверка сохранения реакции

**Мир:** вместо всенаправленного обнаружения объектов агент получает 12 физических каналов:
три угловых сектора для пищи (0–2), опасностей (3–5) и укрытий (6–8),
приближение преграды спереди (9), недостаток энергии (10) и тепловую нагрузку (11).
Первые девять каналов работают только внутри сектора обзора и ограничены линией видимости:
камни перекрывают луч. День/ночь циклически изменяет эффективную дальность зрения;
температура зависит от положения и времени; укрытия уменьшают тепловую нагрузку;
твёрдые камни блокируют движение. Новые модальности — **физические входы**, на
которых может строиться прежний механизм роста виртуальных рецепторов. Базовые
выходы по-прежнему три: левый поворот, правый поворот и тяга.

В интерфейсе виден сектор обзора, видимые и скрытые объекты (последние полупрозрачны,
это информация только для наблюдателя), 12 сенсорных индикаторов, температура,
освещённость, столкновения и количество видимых предметов. Мышью добавляются пища,
опасности, камни и укрытия; угол и радиус зрения настраиваются на лету.

API: `POST /api/world/spawn` с `{"x":0.3,"y":-0.2,"kind":"rock"}`;
`POST /api/control` с `{"fieldOfViewDegrees":140,"visionRange":0.95}`.
Старый формат `{"hazard":true}` для создания опасности поддержан.
Изменения зрения не сбрасывают сеть и сохраняются после сброса модели.

**Новая проверка памяти:** `POST /api/memory/retention` с
`{"seed":1337,"episodes":20,"delaySteps":360}`. Пять сетей с одним seed:
до обучения, после повторений, после паузы, после отвлекающих сигналов и
контроль со случайными парами. Сравниваются амплитуды внутренних ответов на
знакомый и новый стимул, их различимость и изменение относительно исходной
реакции. Проба проходит при замороженной пластичности; исходная живая сеть не
затрагивается. Это измерение **устойчивости отклика**, а не доказательство
узнавания, интеллекта или семантической памяти. Сеть не получает цель/награду.

Дополнительные самостоятельные проверки покрывают геометрию FOV, заслонение,
12 каналов, климатические границы, детерминизм среды, управление зрением и
повторяемость эксперимента с паузой и помехами. Ресурсоёмкие тесты остаются
маленькими, без попарной плотной матрицы нейронов.

## Пространственный перенос опыта (v0.5)

В мире доступны два фиксированных маршрута с одинаковым стартом, целью и числом
камней. Длинная перегородка отделяет агента от пищи, а проход расположен сверху
или снизу. Возле прохода находится визуальный ориентир-укрытие. Зрение по-прежнему
ограничено сектором и перекрывается камнями. В режиме маршрута найденная пища
**не возрождается случайно**, поэтому две проверки можно сравнивать.

В разделе «10 / Пространственный опыт» можно запустить исследование без влияния
на запущенную симуляцию. `POST /api/spatial/experiment` принимает
`{"seed":1337,"episodes":8,"episodeSteps":360,"evaluationSteps":480}`.

Протокол:

1. Две независимые адаптирующиеся сети проходят одинаковые эпизоды по маршруту
   с верхним проходом. Третья проходит эпизоды с отключёнными механизмами обучения.
2. После повторений пластичность, гомеостаз и структурный рост отключаются
   **на время оценки**, чтобы проверка не продолжала обучение.
3. Измеряются пять условий: начальная сеть на старой карте; после опыта на
   старой карте; начальная сеть на новой карте; после опыта на новой карте;
   контроль без обучения на новой карте.
4. Публикуются реальные траектории и метрики достижения цели, ближайшего подхода,
   столкновений, длины пути, энергии и закреплённых связей. Эксперимент не
   считает успех гарантированным и не использует целевые действия или награды.

Число повторений и продолжительность ограничены для запуска на обычном компьютере.
Изменение карт **не сбрасывает нейронную сеть** в живой лаборатории: переключатель
«Маршрут» восстанавливает только стартовую позу и объекты мира. Кнопка общего
сброса полностью пересоздаёт сеть, но сохраняет выбранный маршрут.

### Ограничения интерпретации

Контроль без пластичности имеет тот же начальный seed, но нейросети сами управляют
агентом, поэтому пути и поступающие сенсорные последовательности различаются.
Это не строго уравненное по входам причинное исследование. Различия могут быть
следствием начального состояния и сенсомоторной динамики; успешное достижение
пищи, перенос пространственного навыка или возникновение карты мира **не
предполагаются**. Для дальнейшей проверки полезны предварительно записанные
сенсорные потоки, усреднение по нескольким seed и раздельные оценки поведения.
